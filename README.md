# Anisa Beauty

**Anisa Beauty** یک فروشگاه آنلاین محصولات زیبایی است که با **HTML، CSS و Vanilla JavaScript** طراحی و پیاده‌سازی شده است.

هدف پروژه، ساخت یک تجربه فروشگاهی کامل در سمت Front-End بود؛ به‌گونه‌ای که کاربر بتواند محصولات را جستجو و فیلتر کند، آن‌ها را به علاقه‌مندی‌ها یا سبد خرید اضافه کند و سفارش خود را تا مرحله محاسبه مبلغ نهایی مدیریت کند.

 درباره پروژه

Anisa Beauty با تمرکز روی یک رابط کاربری مدرن، ساده و مناسب فروشگاه‌های حوزه زیبایی طراحی شده است. استفاده از ترکیب رنگ‌های ظریف، کارت‌های محصول، افکت‌های شیشه‌ای، انیمیشن‌های کوچک و طراحی واکنش‌گرا، بخش مهمی از تجربه بصری پروژه را تشکیل می‌دهد.

در این پروژه تلاش شده بسیاری از رفتارهای معمول یک فروشگاه آنلاین، بدون استفاده از Framework و تنها با JavaScript پیاده‌سازی شوند. اطلاعات محصولات و وضعیت‌هایی مانند سبد خرید، علاقه‌مندی‌ها، تم و تنظیمات سفارش نیز در سمت کاربر مدیریت و در localstorage ذخیره می‌شوند.

 امکانات اصلی

 محصولات

* نمایش محصولات به‌صورت Dynamic
* دسته‌بندی محصولات در گروه‌های مختلف
* جستجو بر اساس نام و دسته‌بندی
* فیلتر محصولات
* نمایش جزئیات محصول در Modal
* افزودن محصول به علاقه‌مندی‌ها

سبد خرید

* افزودن و حذف محصولات
* افزایش و کاهش تعداد
* نمایش تعداد محصولات
* محاسبه خودکار قیمت
* Cart Drawer
* صفحه اختصاصی سبد خرید
* حفظ اطلاعات سبد خرید پس از Refresh

 مدیریت سفارش

* انتخاب روش ارسال
* محاسبه هزینه ارسال
* اعمال کد تخفیف
* محاسبه مبلغ نهایی سفارش
* ذخیره تنظیمات سفارش در `localStorage`

 تجربه کاربری

* Dark Mode
* Toast Notification
* Empty State برای حالت‌های بدون نتیجه
* Product Modal
* Contact Modal
* انیمیشن افزودن محصول به سبد خرید
* Hover Effects و Micro-interactions
* طراحی Responsive برای Desktop، Tablet و Mobile
* پشتیبانی از زبان فارسی و چیدمان RTL

ذخیره‌سازی اطلاعات

برای حفظ وضعیت کاربر در مرورگر از `localStorage` استفاده شده است.

اطلاعاتی مانند:

* سبد خرید
* علاقه‌مندی‌ها
* تم انتخاب‌شده
* روش ارسال
* کد تخفیف

پس از Refresh شدن صفحه نیز حفظ می‌شوند.

 ساختار JavaScript

منطق پروژه به چند بخش تقسیم شده تا مسئولیت‌های مختلف از یکدیگر جدا باشند:

products.js
utils.js
app.js
cart.js

products.js اطلاعات محصولات را نگهداری می‌کند، app.js منطق اصلی فروشگاه را مدیریت می‌کند و cart.js مسئول منطق صفحه سبد خرید و محاسبات سفارش است. توابع و منطق‌های مشترک نیز در utils.js قرار گرفته‌اند.

 وضعیت پروژه

Anisa Beauty یک پروژه Front-End است و بخش فروشگاه، سبد خرید و مدیریت سفارش در سمت کاربر پیاده‌سازی شده‌اند.

در نسخه فعلی، پرداخت آنلاین واقعی، Backend، Database و ثبت سفارش روی سرور وجود ندارند و مرحله پرداخت صرفاً به‌عنوان بخش Front-End طراحی شده است.
